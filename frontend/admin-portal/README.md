# Royal Dry Fruits & NuttyDelight - Admin Portal

Frontend Admin Portal built with React, Vite, and TailwindCSS.

## 📁 Directory Structure

```
frontend/admin-portal/
├── public/
├── src/
│   ├── components/
│   │   └── AdminLayout.jsx
│   ├── pages/
│   │   ├── DashboardPage.jsx
│   │   ├── CategoriesPage.jsx
│   │   ├── AddProductPage.jsx
│   │   ├── OrdersPage.jsx
│   │   ├── CustomersPage.jsx
│   │   ├── SettingsPage.jsx
│   │   ├── ProductsPage.jsx
│   │   ├── LoginPage.jsx
│   │   └── SignUpPage.jsx
│   ├── App.jsx
│   ├── index.css
│   └── main.jsx
├── index.html
├── package.json
├── tailwind.config.js
└── vite.config.js
```

## 🎨 Design System
- **Sidebar Background:** `#111c2d`
- **Primary Accent Color:** `#944a00`
- **Surface Background:** `#f7f9fb`
- **Typography:** Inter
- **Icons:** Google Material Symbols Outlined

## 🚀 Running Locally
From `frontend/admin-portal`:
```bash
npm install
npm run dev
```
Open `http://localhost:3000` in your browser.
